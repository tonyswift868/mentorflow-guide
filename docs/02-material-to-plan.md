# 模块03｜从资料到学习计划

**Q07｜资料怎样变成计划里的目录、知识点和小要点？**  
**深度：能讲清原理**

## 先分清目录和课程

目录是资料原有的章节层级，像一本书的目录页；知识点是为了学习目标整理出的内容单元；小要点是一个知识点内可以逐项讲解的材料。三者有关联，但不是同一层东西。计划还会保留每个内容对应的资料段落，让人能追查出处。

## 从已采用资料逐层整理

比如你要学一份有“账号”“同步”“异常恢复”章节的软件说明。开始时，程序先保留用户采用的资料，并按章节标题和段落整理成可选目录；你可以检查范围、删掉不打算学的部分，再确认目录。确认后，计划流程根据目标和已选章节继续整理知识结构，而不是把整本资料不加区分地塞给老师。

整理时，知识点和小要点会带着指向资料段落的引用，讲义摘句也能回到原文。规划提示要求模型把目标需要、但资料没有覆盖的部分标成缺口；这是生成结构时给模型的约束，不能保证它一定识别所有语义缺口。比如“同步”知识点可以引用“本地待传记录”和“服务器确认”两段原文；读者仍要检查它们是否真的支持这个知识点。

目录和知识结构都可以检查、调整。用户确认材料范围后，程序才按这个范围生成并保存计划；保存前会核对引用是否仍指向已采用资料，但不会证明引用在语义上足以支持知识点。这个流程提高了可检查性，仍需人检查目录、目标和出处是否相符。

## 可以直接说

“资料先被整理成带层级和段落出处的目录，用户检查范围并确认后，系统再按学习目标组织知识点和小要点。规划提示要求标出资料覆盖缺口，程序会检查引用仍属于已采用资料，但不判断原文在语义上是否支持该要点，所以结构和出处仍要人工核对。”

### 资料怎样变成计划中的知识点？

- 程序先从用户采用的资料整理章节目录和段落，供检查与选择范围。
- 确认范围后，按学习目标把资料组织成知识点和小要点。
- 要点保留原文来源映射；提示词要求标缺口，引用归属检查不等于语义覆盖验证。

### 追问加练

面试官可能追问：AI能不能把资料没有讲的内容也补进计划？  
一句答法：不能把推断说成资料覆盖；缺失内容应作为缺口提示，再由用户补资料或调整范围。
