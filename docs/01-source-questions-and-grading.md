# 模块02｜原题抽取与判分边界

**Q06｜为什么只抽资料里的原题，客观题由程序比对，问答题让用户勾要点？**  
**深度：必须能背**

## 先知道题目从哪里来

这里的“原题”指用户资料中本来就有题干和答案的练习。抽题是把这些内容定位出来、按题型整理；它不等于让模型照着一段课文编一道新题。客观题有资料给出的标准答案，可以按规则比较。问答题的表达方式很多，系统让学习者看过自己的回答和参考答案后，自己核对要点。

## 按来源和答案形式分开处理

假设一份资料有一道选择题：“水在标准大气压下的沸点是多少？”并列出选项和标准答案。程序从原文识别题干、选项与带有答案标记的内容；如果原资料没有标准答案，程序不会替它补一个。模型只帮忙整理已找到的候选题，不能新编题、改写题干或补答案。这样每一道练习都能回到原资料核对，发现抽取错误时也知道从哪里查。

学生选中选项后，程序可把选择结果与答案比较。填空会按允许的文本形式比对，计算题比较数值；这些判断不需要模型猜测学生“意思差不多”。遇到主观问答则不同：比如“说明这个同步设计解决了什么问题”，两种正确说法可能用词不同。系统展示参考答案和要点，让学生看自己的回答后勾选覆盖了哪些点，并自评是否正确。勾选是在帮助复盘，不代表系统客观证明了掌握程度。

这个设计把“题目忠实于资料”和“判分可解释”放在一起：原题有出处，客观答案走明确规则，开放表达由学习者参与判断。它也划清限制：资料本身写错时，照原文抽取不能自动纠正；主观题的自评也不是独立测验结论。

## 可以直接说

“我把练习限定为资料中已有的原题，避免模型另编题或补造标准答案；题干和答案都保留来源。选择、填空和计算等客观题按程序规则比较。主观问答的表达不止一种，所以让学习者对照参考答案勾要点并自评。这样判分边界清楚，但自评不等于系统证明学会了。”

### 为什么采用原题、程序判客观题、问答由用户勾要点？

- 只整理资料已有题目，题干和答案保留出处，不让模型编题或补答案。
- 选择、填空、计算等客观答案可按明确规则由程序比对。
- 主观表达方式多，由学习者对照参考答案勾要点并自评，不宣称客观证明掌握。

### 追问加练

面试官可能追问：用户勾选了全部要点，能不能说他已经掌握？  
一句答法：不能，这表示用户自评覆盖了参考要点，程序记录的是这次自评结果。
